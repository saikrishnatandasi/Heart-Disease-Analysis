## 🫀 Heart Disease Analysis Project

I'm excited to share my recent data analytics project focused on heart disease prediction and visualization!

### Project Overview:
I analyzed a dataset of 1,025 patients to identify key risk factors and patterns in heart disease occurrence. Using Python for data processing and machine learning, along with Power BI for visualization, I created a comprehensive analytical solution that provides immediate insights into patient profiles and risk factors.

### Key Findings:
- 51.32% of the dataset shows heart disease indicators
- The average cholesterol level of patients in the study is 246.00 mg/dl
- Average resting blood pressure is 131.61 mmHg
- Maximum heart rate recorded: 202 bpm
- Most patients (47.02%) showed a flat slope in their ST segment during exercise
- Typical angina was the most common chest pain type among patients

### Machine Learning Model:
I implemented a Random Forest Classifier that achieved 95% accuracy in predicting heart disease based on patient health metrics. The model particularly focused on:
- Cholesterol levels
- Blood pressure measurements
- Other key cardiovascular indicators

The predictive model enables healthcare providers to input patient metrics and receive an immediate assessment of heart disease risk, potentially supporting early intervention.

### Power BI Dashboard:
The interactive dashboard visualizes critical metrics with:
- KPI cards showing aggregate statistics
- Distribution charts for patient demographic segmentation
- Comparative visualizations of heart health metrics by gender and condition
- Risk factor correlation displays
- Real-time filtering capabilities for customized analysis

### Tech Stack:
- **Data Processing**: Python, Pandas, NumPy
- **Data Analysis**: Jupyter Notebook, Scikit-learn
- **Visualization**: Matplotlib, Seaborn, Power BI
- **Machine Learning**: Random Forest Classifier
- **Statistical Analysis**: SciPy
